СНВ Контроль — загрузка в GitHub Pages с iPhone

ФАЙЛЫ
- index.html — приложение
- manifest.json — настройки установки на главный экран
- service-worker.js — кэширование файлов для запуска без интернета
- icon-192.png и icon-512.png — иконки

КАК ЗАГРУЗИТЬ С IPHONE
1. На github.com создай публичный репозиторий snv-control.
2. В репозитории нажми Add file → Upload files.
3. Загрузи ВСЕ пять файлов выше (index.html, manifest.json, service-worker.js, icon-192.png, icon-512.png) в корень репозитория. README_GITHUB.txt и ИНСТРУКЦИЯ.txt загружать необязательно.
4. Нажми Commit changes.
5. Открой Settings → Pages.
6. В разделе Build and deployment выбери Deploy from a branch, branch main, folder /(root), нажми Save.
7. Дождись публикации и открой адрес https://ТВОЙ-ЛОГИН.github.io/snv-control/ в Safari.
8. В Safari нажми Поделиться → На экран Домой. Если предложено «Открывать как веб-приложение», включи переключатель.
9. Первый запуск сделай с интернетом, открой приложение и подожди немного, чтобы файлы закэшировались. Затем проверь офлайн: включи авиарежим и запусти иконку.

ВАЖНО
- Данные станций и визитов хранятся локально в браузере этого iPhone, не в GitHub.
- Не очищай данные Safari и не удаляй веб-приложение без резервной копии.
- В приложении используй Настройки и данные → Экспорт данных и храни JSON-копию в приложении «Файлы»/iCloud Drive.
- После обновления файлов на GitHub иногда нужно открыть сайт с интернетом, чтобы получить новую версию.
- Репозиторий публичный: не загружай в него резервные копии с рабочими данными.
