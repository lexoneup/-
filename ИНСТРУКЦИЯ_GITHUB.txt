ИНСТРУКЦИЯ: УСТАНОВКА СНВ КОНТРОЛЬ НА IPHONE ЧЕРЕЗ GITHUB PAGES

1. Создай аккаунт GitHub или войди: https://github.com
2. Создай новый PUBLIC repository с именем snv-control.
3. В репозитории выбери Add file → Upload files.
4. Загрузи пять файлов из комплекта: index.html, manifest.json, service-worker.js, icon-192.png, icon-512.png.
5. Нажми Commit changes.
6. Открой Settings → Pages. В Build and deployment выбери Deploy from a branch, Branch: main, Folder: /(root), затем Save.
7. Подожди публикацию. Открой адрес https://ТВОЙ-ЛОГИН.github.io/snv-control/ в Safari (вместо ТВОЙ-ЛОГИН укажи логин GitHub).
8. Нажми кнопку «Поделиться» в Safari → «На экран Домой» → «Добавить».
9. Запусти приложение с иконки, пока есть интернет. Затем включи авиарежим и проверь, что оно открывается.
10. Добавь тестовую станцию, закрой приложение, открой снова и проверь, что станция сохранилась. После проверки удали тестовую станцию и добавь рабочие.

РЕЗЕРВНАЯ КОПИЯ
В приложении открой «Настройки и данные» → «Экспорт данных». Сохрани JSON-файл в «Файлы» или iCloud Drive. Повторяй экспорт после важных изменений. Не загружай файл резервной копии в публичный GitHub-репозиторий.

ПРИМЕЧАНИЯ
- После первой загрузки нужен интернет, чтобы кэшировать файлы приложения.
- Офлайн-режим обеспечивается service-worker.js; сайт должен открываться по HTTPS через GitHub Pages.
- Данные остаются на конкретном iPhone и не синхронизируются автоматически между устройствами.
- Не очищай данные Safari и не удаляй приложение, пока не сделал резервную копию.
